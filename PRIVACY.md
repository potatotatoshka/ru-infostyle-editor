# Политика конфиденциальности

Последнее обновление: 17 сентября 2026 года.

`ru-infostyle-editor` — набор инструкций и справочных материалов для редактуры русскоязычных текстов. Он не запускает собственный сервер, не использует API третьих сторон и самостоятельно не собирает, не хранит и не передаёт пользовательские данные.

Текст, который пользователь отправляет в ChatGPT или Codex при работе с плагином, обрабатывается соответствующей платформой по её условиям и политике конфиденциальности. Передавайте только те данные, которые вы вправе раскрывать. Не публикуйте в GitHub Issues конфиденциальные тексты, персональные данные и секреты.

Вопросы по проекту направляйте через [GitHub Issues](https://github.com/potatotatoshka/ru-infostyle-editor/issues).
